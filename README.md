# Apex Storefront 🛒

A modern full-stack e-commerce platform built with Next.js, featuring a customer storefront, shopping cart, order management, and an admin dashboard.

## 🚀 Features

### Customer

- Browse products
- Search products
- Filter products by category
- View product details
- Quick product preview
- Add products to cart
- Manage cart items
- View order history
- Track order status
- Customer profile

### Admin

- Admin dashboard
- Add new products
- Edit products
- Delete products
- Manage product inventory
- View customer orders
- Update order status
- Monitor store activity

### 🛍️ Storefront

- Modern responsive UI
- Product categories
- Product stock indicators
- Shopping bag/cart
- Product search and filtering
- Real-time order status tracking
- Customer and admin views

## 🛠️ Tech Stack

- **Next.js**
- **React**
- **JavaScript**
- **MongoDB**
- **Node.js**
- **CSS**
- **JWT Authentication**
